# Ronin Home (branch `ronin-home`)
Ad-free TV home screen for the family's Google TV (TCL, Android 14). Separate from Ronin Browser (branch `main`).
Clock hero, My Apps (original banners), Kids row, Top 10 Movies / Shows, New Releases, Coming Soon (TMDB, India, only
subscribed services), My subscriptions switches, Castle — New, clock screensaver, Home-button takeover by an
accessibility service (Google TV home stays enabled so Gemini keeps working).
Build + Android TV emulator check: `.github/workflows/home.yml` → prerelease `ronin-home`.
